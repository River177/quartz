## 课程章节概览

- [CH1-引言](CH1-引言.md)：数据库、DBMS、DBS 的概念与差异，ANSI-SPARC 三层架构及数据独立性、技术演进与课程框架。
- [CH2-数据模型](CH2-数据模型.md)：层次/网络/关系/ER/面向对象等模型的结构、约束与操作，关系代数与演算要点以及模型发展趋势。
- [CH3-用户界面与 SQL 语言](CH3-用户界面与 SQL 语言.md)：SQL 查询语义、集合/聚合/子查询/CTE/递归、视图与 DML、嵌入式与动态 SQL 及游标使用方式。
- [CH4-数据库管理系统](CH4-数据库管理系统.md)：DBMS 架构、文件与索引、查询优化策略、日志恢复、事务并发与锁/死锁管理。
- [CH5-安全性与完整性约束](CH5-安全性与完整性约束.md)：认证授权、角色、审计、统计数据库防护、CHECK/ASSERTION/触发器等完整性机制。
- [CH6-数据库设计](CH6-数据库设计.md)：数据依赖与 1NF/2NF/3NF 示例、ER 建模、面向数据设计流程以及需求→概念→逻辑→物理的实践要点。
- [[并发与锁机制]]： 主要是并发和锁的问题。
