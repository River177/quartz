这篇论文提出的方法叫 **SUPT：Subgraph-level Universal Prompt Tuning**，中文可以理解为 **子图级通用图提示调优**。核心思想是：

> 不是像 GPF 那样给所有节点加同一个 prompt，也不是像 GPF-plus 那样只根据节点自身特征生成 prompt，而是根据节点所在的局部子图上下文，为不同子图/节点分配不同 prompt，从而更好捕获图结构中的局部语义。
> 
> 

---

## 1\. 方法动机

已有图 prompt tuning 方法主要有两类问题。

第一类方法，例如 GPPT、GraphPrompt，通常和特定预训练任务绑定，比如 edge prediction 或 link prediction。因此如果预训练任务换成 GraphCL、AttrMasking、ContextPred，这些方法就不一定适用。

第二类方法是 GPF / GPF-plus，它们更通用，可以适配多种预训练策略。GPF 的做法是在输入节点特征上加 prompt：

$$
x_i^* = x_i + p
$$

GPF-plus 进一步允许不同节点使用不同 prompt：

$$
x_i^* = x_i + p_i
$$

但问题是，GPF-plus 的 prompt 主要由节点自身特征决定，并没有充分考虑节点所处的局部图结构。图数据的关键不只是节点类型，还包括节点所在的邻域上下文。论文图 2 中也强调：同类型节点在不同子图环境中，可能应该使用不同 prompt。



所以 SUPT 的目标是：

> 在保持“通用 prompt tuning”能力的前提下，把 prompt 从节点级提升到子图级，使 prompt 能感知局部结构上下文。

---

# 2\. 总体框架

SUPT 仍然遵循 graph prompt tuning 的基本范式：

```
预训练阶段：  
    先用任意图预训练策略得到一个预训练 GNN fθ  
  
下游适配阶段：  
    冻结预训练 GNN fθ  
    只训练 prompt 参数 ψ 和任务投影头 hφ  
    通过 prompt 修改输入图特征，使其适配下游任务
```

普通 fine-tuning 优化的是：

$$
\max_{\theta,\phi} P_{f_\theta,h_\phi}(y|G)
$$

也就是更新整个预训练 GNN。

而 prompt tuning 优化的是：

$$
\max_{\psi,\phi} P_{f_\theta,h_\phi}(y|g_\psi(G))
$$

其中：

-   $f_\theta$：预训练 GNN，冻结；
    
-   $h_\phi$：下游任务投影头；
    
-   $g_\psi(G)$：prompt function，把原图变成 prompted graph；
    
-   $\psi$：prompt 参数，参数量远小于 $\theta$。
    

SUPT 的重点就是设计这个 $g_\psi(G)$。

---

# 3\. 先看 GPF / GPF-plus 怎么做

SUPT 是在 GPF-plus 基础上改进的，所以先理解 GPF-plus 很重要。

GPF-plus 会准备 $k$ 个可学习 basis prompt：

$$
b_1,b_2,\dots,b_k
$$

每个节点 $v_i$ 的 prompt 是这些 basis prompt 的加权和：

$$
p_i = \sum_{j=1}^{k} \alpha_{i,j}b_j
$$

其中权重 $\alpha_{i,j}$ 由节点自身特征 $x_i$ 计算：

$$
\alpha_{i,j} = \frac{ \exp(a_j^\top x_i) }{ \sum_{l=1}^{k}\exp(a_l^\top x_i) }
$$

然后节点特征变为：

$$
x_i^* = x_i + p_i
$$

GPF 是 GPF-plus 的特殊情况，也就是 $k=1$，所有节点共享同一个 prompt。

GPF-plus 的不足是：它只看节点特征 $x_i$，没有显式利用节点周围的子图上下文。

---

# 4\. SUPT 的核心：根据子图上下文分配 prompt

SUPT 仍然是在输入节点特征上加 prompt：

$$
x_i^* = x_i + p_i
$$

但它改变了 $p_i$ 的计算方式。

SUPT 不再只根据节点自身特征 $x_i$ 计算 prompt 权重，而是先通过一个简单 GNN/GCN 聚合 $m$\-hop 邻域信息，让权重感知节点所在的子图上下文。

论文给出的公式是：

$$
p_i = \sum_{j=1}^{k} \sigma(\alpha)_{i,j} b_j
$$

其中：

$$
\alpha = (\tilde{D}^{-\frac{1}{2}}\tilde{A}\tilde{D}^{-\frac{1}{2}})^m \left( X \oplus \sum_{j=1}^{k} b_j \right)W
$$

这里每个符号含义是：

-   $\tilde{A}$：加入自环后的邻接矩阵；
    
-   $\tilde{D}$：对应的度矩阵；
    
-   $m$：聚合几跳邻域信息；
    
-   $X$：原始节点特征矩阵；
    
-   $b_j$：第 $j$ 个 prompt basis；
    
-   $k$：prompt basis 数量，也可以理解为子图簇数量；
    
-   $W\in \mathbb{R}^{d\times k}$：可学习权重矩阵；
    
-   $\alpha\in \mathbb{R}^{N\times k}$：每个节点对每个 prompt basis 的分配分数；
    
-   $\sigma$：非线性分配函数，可以是 softmax，也可以是 top-rank selection。
    

直观理解：

> SUPT 先用一个轻量图传播操作，让节点的 prompt 分配权重包含邻域上下文信息。这样两个节点即使自身特征相似，只要处在不同子图结构中，也可能被分配不同 prompt。

---

# 5\. 为什么叫 subgraph-level？

SUPT 中的 $k$ 个 prompt basis 可以理解为 $k$ 个“子图级 prompt 模板”。

通过 $\alpha$，模型会判断每个节点更属于哪个子图模式，或者应该受哪些子图 prompt 影响。

因此，SUPT 不是显式先把图切成若干子图再分别训练 prompt，而是通过类似图池化/聚类的方式，学习节点到子图 prompt basis 的 assignment。

论文也说明，SUPT 的思想受到 graph pooling 方法启发：

-   SUPTsoft 类似 soft cluster pooling；
    
-   SUPThard 类似 node selection pooling。
    

但 SUPT 不会真的压缩图，也不会删除节点，只是在原始输入特征上加 prompt，因此不会破坏原图结构。

---

# 6\. SUPTsoft：软分配版本

SUPTsoft 使用 softmax 作为 $\sigma$。

也就是说，每个节点都会对所有 prompt basis 有一个权重：

$$
\sigma(\alpha)_{i,j} = softmax(\alpha_{i,:})_j
$$

然后节点 $v_i$ 的 prompt 是所有 basis 的加权和：

$$
p_i = \sum_{j=1}^{k} softmax(\alpha)_{i,j}b_j
$$

最后：

$$
x_i^* = x_i + p_i
$$

SUPTsoft 的特点是：

1.  每个节点都会被加上 prompt；
    
2.  每个节点可以同时受到多个 prompt basis 的影响；
    
3.  prompt 分配是连续、可微的；
    
4.  更像“软聚类”的子图 prompt 分配。
    

可以理解为：

```
节点 i 可能 70% 属于子图模式 1，  
20% 属于子图模式 2，  
10% 属于子图模式 3。  
因此它的 prompt 是三个 basis 的加权组合。
```

---

# 7\. SUPThard：硬选择版本

SUPThard 使用 top-rank selection。

对于第 $k$ 个 prompt basis，模型从所有节点中选择得分最高的一部分节点：

$$
idx = top\text{-}rank(\alpha_{:,k}, \lceil rN \rceil)
$$

其中：

-   $r\in(0,1]$：pooling ratio；
    
-   $N$：节点数；
    
-   $\lceil rN\rceil$：被选中的节点数量。
    

然后只给这些被选中的节点加第 $k$ 个 prompt：

$$
X^*_{idx,:} = X_{idx,:} + \delta(\alpha_{idx,k}) \odot b_k
$$

其中：

-   $\delta$：激活函数，例如 sigmoid；
    
-   $\odot$：逐元素乘法或广播乘法；
    
-   $b_k$：第 $k$ 个 prompt basis。
    

SUPThard 的特点是：

1.  不是所有节点都会被加 prompt；
    
2.  每个 basis 只影响 top-ranked 节点；
    
3.  一个节点可能不被任何 basis 选中，也可能被多个 basis 选中；
    
4.  更像“硬选择”的子图 prompt。
    

直观理解：

```
第 1 个 prompt basis 只作用于最符合子图模式 1 的节点；  
第 2 个 prompt basis 只作用于最符合子图模式 2 的节点；  
未被选中的节点保持原始特征不变。
```

---

# 8\. SUPTsoft 和 SUPThard 的区别

| 方法 | 分配方式 | 是否所有节点都有 prompt | 特点 |
| --- | --- | --- | --- |
| SUPTsoft | softmax 软分配 | 是 | 每个节点是多个 basis 的加权组合 |
| SUPThard | top-rank 硬选择 | 否 | 只给高分节点加对应 prompt |

SUPTsoft 更平滑、训练更稳定；SUPThard 更稀疏，强调只对关键子图节点施加 prompt。

论文实验中，两者都表现优于 GPF/GPF-plus；SUPTsoft 通常略稳定，SUPThard 在部分任务上也很强。



---

# 9\. SUPT 的训练流程

完整训练过程可以理解为：

```
输入：  
    图 G=(V,E)  
    节点特征 X  
    冻结的预训练 GNN fθ  
    下游任务标签 y  
  
步骤：  
1\. 初始化 k 个 prompt basis：b1, b2, ..., bk  
2\. 使用简单 GCN/SGC 聚合 m-hop 邻域上下文  
3\. 得到每个节点对每个 basis 的分配分数 α  
4\. 根据 SUPTsoft 或 SUPThard 得到节点 prompt pi  
5\. 修改输入节点特征：  
       xi\* = xi + pi  
6\. 将 prompted graph 输入冻结的预训练 GNN：  
       zi = fθ(X\*, A)  
7\. 用任务投影头 hφ 做下游预测  
8\. 只更新 prompt 参数 ψ 和投影头 φ，不更新 fθ
```

其中 SUPT 的可学习参数主要是：

-   prompt basis $b_1,\dots,b_k$；
    
-   分配矩阵计算中的 $W$；
    
-   下游投影头 $h_\phi$。
    

预训练 GNN 的参数 $\theta$ 全部冻结。

# 10\. 理论分析：为什么 SUPT 仍然是 universal prompt？

GPF 的一个重要卖点是 universal capability，也就是理论上可以模拟任意 prompt function 的效果。

SUPT 虽然不是给所有节点统一加 prompt，而是只给某些子图/节点加 prompt，但论文证明它仍然具有 universal capability。

论文的定理大意是：

给定任意 prompt function $\Psi_t(\cdot)$，它可以把输入图：

$$
G=(X,A)
$$

变成某个 prompted graph：

$$
\hat{G}=(\hat{X},\hat{A})
$$

那么对于任意非空节点子集 $S\subseteq V$，存在一个 prompt 向量 $\hat{p}$，使得只对子集 $S$ 中的节点加 prompt：

$$
X_s' = \begin{cases} X_s + \hat{p}, & s\in S \\ X_s, & s\notin S \end{cases}
$$

也可以让预训练 GNN 得到等价表示：

$$
f(X', A)=f(\hat{X},\hat{A})
$$

这说明：

> 即使 prompt 只加在子图节点上，SUPT 理论上也可以达到任意 prompt function 的表达能力上界。

所以 SUPT 既保持了 GPF 的通用性，又比 GPF 更能捕获子图上下文。

# 11\. 和 GPF / GPF-plus 的本质区别

论文图 2 很清楚地展示了几种方法的区别。



| 方法 | Prompt 粒度 | 核心问题/特点 |
| --- | --- | --- |
| Fine-tuning | 更新整个 GNN | 参数量大，可能 catastrophic forgetting |
| GPF | 全图共享 prompt | 所有节点加同一个 prompt，表达力弱 |
| GPF-plus | 节点类型级 prompt | 根据节点特征分配 prompt，但缺少结构上下文 |
| SUPT | 子图级 prompt | 根据局部结构上下文分配 prompt |

SUPT 的关键优势在于：

> 相同类型的节点，如果处于不同子图环境中，可以获得不同 prompt。

例如在分子图中，两个碳原子可能节点类型相同，但一个在苯环中，一个在羧基附近，它们对分子性质的贡献不同。GPF-plus 可能只看到它们都是 C，而 SUPT 能通过邻域结构给它们不同 prompt。

---

# 12\. 为什么 SUPT 参数效率高？

fine-tuning 需要更新整个 GNN，参数量大约是百万级。

而 SUPT 只学习少量 prompt basis 和分配参数，参数量通常只有几千级，远小于 fine-tuning。

论文表 1 中显示：

-   Fine-tuning 参数量约为 1.8M 到 2.7M；
    
-   GPF 参数量约 0.3K；
    
-   GPF-plus 参数量约 3K 到 12K；
    
-   SUPT 参数量约 0.6K 到 3K。
    

也就是说，SUPT 的参数量甚至小于 GPF-plus，但性能通常更好。

# 14\. 实验结论

论文主要发现：

1.  SUPT 在 full-shot 场景下明显优于 fine-tuning、GPF、GPF-plus；
    
2.  SUPT 在 50-shot few-shot 场景下提升更明显；
    
3.  SUPTsoft 和 SUPThard 都有效；
    
4.  SUPT 只用极少参数，就能达到甚至超过 fine-tuning；
    
5.  SUPT 对不同预训练策略都适用，体现了 universal prompt tuning 能力。
    

论文报告中，SUPT 在 full-shot 的 45 个实验中大多数超过 fine-tuning，在 few-shot 场景下也取得更大平均提升。



---

# 15\. 一句话总结

SUPT 的核心方法是：

> 在冻结预训练 GNN 的情况下，通过一个轻量的子图级 prompt 分配机制，根据节点的局部结构上下文为不同子图/节点添加不同 prompt，从而同时保持通用性、参数效率和更强的图上下文建模能力。
