这篇论文的方法，主线其实很清楚：

**先重新解释 graph prompt learning 到底该做什么，再基于这个结论，提出一个只在输入图拓扑上做 prompt 的统一方法 UniPrompt。** 它的目标不是让 prompt 去“代替分类器适配下游”，而是让 prompt 去**释放预训练模型本身的能力**，同时把“适配下游标签”的工作交给一个很轻的 classifier。

先说作者的出发点。论文把现有 GPL 分成三类：  
一类是 **input-level prompt**，在输入图上加 prompt；  
一类是 **layer-wise prompt**，在模型各层里插 prompt；  
一类是 **representation-level prompt**，在预训练模型输出表示后再加 prompt。图 1 就是在概括这三类。作者认为现有方法有两个根本问题：  
第一，不同 prompt 机制到底在起什么作用，没有统一认识；  
第二，这些方法对不同预训练模型、不同下游场景，尤其跨域或同配到异配这种分布变化场景，适应性不稳定。
![[Pasted image 20260419213330.png]]

论文最关键的理论结论，是对 **representation-level prompt** 的重新解释。作者定义了一个线性的 prompt 函数 $T(h)=W_T h+b_T$，再接一个线性分类器 $C(h)=W_C^\top h$。然后证明：  
**“表示级 prompt + 线性分类器”在函数空间上等价于“一个新的线性分类器”**，并且在优化目标上也是等价的。也就是说，这类方法本质上并没有真正“激活预训练模型的能力”，而更像是在做一个稍微复杂一点的 linear probe。基于这个结论，作者提出他们的核心观点：  
**graph prompt 应该重点负责让输入更适合预训练模型，而 classifier 负责适配下游标签。**

顺着这个观点，UniPrompt 只保留一种 prompt 方式：**input-level topological prompt**。  
它不改预训练 encoder 参数，encoder $f_\theta$ 始终冻结；也不在表示层搞复杂 token，而是直接生成一个**可学习的拓扑 prompt graph**，再把它和原始图融合后送进预训练模型。最后，只联合训练两部分：

-   prompt 参数 $\Psi$
    
-   一个轻量 projection head / classifier $g_\phi$。

具体方法分四步。

第一步是 **prompt initialization**。  
作者先用节点特征之间的余弦相似度，构造一个 **kNN prompt graph** 作为初始拓扑 prompt。对任意两个节点 $v_i,v_j$，先算相似度：

$$
S_{ij}=\frac{x_i x_j^\top}{\|x_i\|_2\|x_j\|_2}
$$

然后对每个节点只保留 top-k 相似邻居，形成初始 prompt 邻接矩阵：

$$
(\tilde A^{init})_{ij}= \begin{cases} S_{ij}, & S_{ij}\in \text{top-k}\{S_{i\cdot}\}\\ 0, & \text{otherwise} \end{cases}
$$

这里的直觉是：  
与其去改特征，不如先补一张“语义相近节点之间应该互相传消息”的辅助拓扑。特别是在 heterophily 图里，原图边不一定可靠，但特征近邻反而可能更能反映任务相关关系。


第二步是 **parameterization**。  
初始 kNN 图只是起点，真正可学习的是每条 prompt edge 的强度。对于每条非零边 $(\tilde A^{init})_{ij}$，作者给它分配一个可学习标量 $w_{ij}$，所有这些 $w_{ij}$ 构成 prompt 参数 $\Psi$。然后用一个带门控的 ELU 形式，把它变成最终 prompt adjacency：

$$
\tilde A_{ij} = \text{ELU}(w_{ij}\cdot \alpha - \alpha)+1
$$

其中 $\alpha$ 是控制形状的超参数。这样设计有两个作用：

-   保证边权非负；
    
-   允许模型自动决定哪些 prompt 边该被放大，哪些该被压到接近 0，相当于自适应剪枝。

第三步是 **bootstrapped prompt integration**，这一步非常关键。  
作者强调，不能直接用 prompt graph 去替换原始图 $A$，因为 few-shot 下这样做很容易过拟合，甚至导致 model collapse。于是他们提出一个**逐步融合**策略。设第 $t$ 个训练 epoch 送入预训练模型的邻接矩阵为 $\hat A^{(t)}$，则：

$$
\hat A^{(t)} = \tau \hat A^{(t-1)} + (1-\tau)\tilde A
$$

其中 $\hat A^{(0)}=A$，$\tau\in[0,1]$ 控制“保留原图”与“引入 prompt 图”的比例。  
这意味着 UniPrompt 不是粗暴地改图，而是**一点点把 prompt topology 注入原图拓扑里**。原图始终保留，所以作者说它是“preserving the input graph”。论文第 9 页的超参数分析还说明：当 $\tau=1$ 时，相当于完全不注入 prompt 图，这就是方法退化成无 prompt 的情况。

第四步是 **joint optimization with classifier**。  
得到融合后的图 $\hat G=(\hat A,X)$ 后，用冻结的预训练模型 $f_\theta$ 计算节点表示，再接一个轻量分类头 $g_\phi$。最终优化目标是：

$$
\min_{\phi,\Psi}\frac{1}{|V_L|}\sum_{v_i\in V_L} \ell_D\big(g_\phi(f_\theta(p_\Psi(A,X))_i),y_i\big)
$$

其中 $V_L$ 是少量标注节点，$\ell_D$ 一般就是交叉熵。  
这里非常符合他们前面的理论观点：

-   **prompt $\Psi$** 负责把输入图改造成更适合预训练模型的样子；
    
-   **classifier $\phi$** 负责适配具体下游标签空间。

所以，UniPrompt 的方法本质上不是“再发明一种更复杂的 prompt token”，而是把 GPL 的角色重新分工了：

-   不让 prompt 去承担 classifier 的职责；
    
-   不让表示级 prompt 和 linear probe 做重复工作；
    
-   而是只在输入拓扑层面做一件事：**补充和重塑消息传播路径**。
    

为什么作者觉得这种方法更适合复杂场景，尤其 heterophily 和 cross-domain？  
因为预训练模型大多隐含某种 homophily 假设，或者至少依赖已有拓扑传播。如果下游图分布变了，尤其从同配切到异配，直接在表示层做 prompt 往往只是“后处理表示”，没法真正改变消息传播过程；而 UniPrompt 通过学习一张 kNN prompt 图，相当于在输入层补充了“哪些节点更应该互相通信”的新结构。再加上 bootstrapped 融合不会完全破坏原图，因此既能引入新拓扑，又不至于训练崩掉。

如果按论文自己的逻辑把 UniPrompt 流程压成一条链，就是：

**原始图 $G=(A,X)$ → 用特征相似度构造初始 kNN prompt 图 $\tilde A^{init}$ → 用可学习边权得到 $\tilde A$ → 通过 bootstrapping 与原图逐步融合成 $\hat A$ → 送入冻结的预训练 encoder $f_\theta$ → 用轻量 classifier $g_\phi$ 在 few-shot 标注节点上训练。**

一句话总结这篇方法：

**UniPrompt 先从理论上说明表示级 prompt 本质接近 linear probe，因此将 graph prompt learning 的重点转向 input-level adaptation；具体上，它用特征相似度构造 kNN 拓扑 prompt，再通过可学习边门控和 bootstrapped 融合，把 prompt 图逐步注入原始图中，最后在冻结的预训练模型上联合训练 prompt 与轻量分类器，从而让任意预训练图模型更稳定地适配同域和跨域 few-shot 下游任务。**
