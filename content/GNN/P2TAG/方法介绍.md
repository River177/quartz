这篇论文提出的 **P2TAG**，核心可以概括成一句话：

**它把文本属性图上的 few-shot 节点分类，做成了“先联合预训练 LM 和 GNN，再用图提示 + 文本提示一起做下游 prompt learning”的统一框架。** 和以往方法相比，它不是先把文本离线编码成静态 node feature 再跑 GNN，也不是只在 LM 侧做文本 prompt，而是同时利用**原始文本**和**图结构**。


整篇方法可以拆成两大阶段：

-   **预训练阶段**：联合训练 LM 和 GNN，目标是 masked language modeling
    
-   **提示阶段**：设计 graph-text mixed prompt，用很少可训练参数做 few-shot 节点分类。

---

## 1\. 它想解决什么问题

作者针对的是 **TAG（text-attributed graph）**，也就是每个节点都带原始文本的图。  
他们认为现有 few-shot 节点分类方法有两个明显问题：

第一，很多方法直接在**预处理好的 node features**上训练，忽略原始文本，性能很依赖特征预处理质量。  
第二，已有 prompt 方法在 TAG 上往往只顾一边：

-   要么偏 **graph prompt**
    
-   要么偏 **text prompt**  
    但 TAG 同时有文本和图结构，所以只做单边 prompt 往往不够。
    
    
    

因此他们提出 P2TAG：  
**Pre-Training and Prompting for few-shot node classification on TAGs**。它的重点不只是“pre-train + prompt”，而是：

1.  **LM 和 GNN 联合预训练**
    
2.  **图提示和文本提示联合设计**。
    
    
    

---

## 2\. 第一阶段：联合预训练 LM 和 GNN

### 2.1 总体思路

P2TAG 不采用传统两步法：

-   第一步先把文本编码成静态向量
    
-   第二步再把向量喂给 GNN。


作者认为这种做法会有信息损失，所以提出一个 **end-to-end 的自监督框架**，直接在 TAG 上联合训练 LM 和 GNN。



在他们的框架里：

-   **LM** 负责从原始文本里提取语义
    
-   **GNN** 负责在图上传播邻居信息
    
-   两者通过同一个 self-supervised objective 联合优化。
    
    
    

形式上，他们把自监督学习写成：

$$
\theta_1^*,\theta_2^*,\theta_3^* = \arg\min_{\theta_1,\theta_2,\theta_3} L_{SSL}(f^{GNN}_{\theta_1},f^{LM}_{\theta_2},f^{Head}_{\theta_3},G)
$$

最后得到表示：

$$
Z = f^{GNN}_{\theta_1^*}(G,X), \quad X = f^{LM}_{\theta_2^*}(S)
$$

也就是先由 LM 编码文本，再由 GNN 在图上传播。



---

### 2.2 为什么选 MLM 作为自监督目标

论文这里有个很重要的判断：  
LM 和 GNN 联训比普通图自监督更难，因为：

-   LM 参数量大
    
-   GNN 参数量小
    
-   如果自监督任务太简单，很容易过拟合。
    
    
    

所以作者没有用常见图对比学习，而是直接采用 **masked language modeling（MLM）**。  
这一步是 P2TAG 和很多图自监督方法差异最大的地方之一。



具体过程是：

1.  对每个节点 $v_i$ 的文本序列 $s_i=[T_1,\dots,T_{n_i}]$，随机按 mask rate $p$ 把部分 token 替换成 `[MASK]`
    
2.  把被 mask 的文本送进 LM
    
3.  LM 输出每个 token 的 hidden state，其中 `[CLS]` 的输出 $o_0$ 作为这个节点的文本表示
    
4.  再把所有节点的 `[CLS]` 向量作为 GNN 的输入做图传播，得到节点表示 $H=f_{GNN}(G,X)$。
    
    
    

然后，对节点 $v_i$ 的每个 token 输出 $o_t$，再和该节点经过图传播后的表示 $h_i$ 拼接，送进一个 MLP：

$$
z_t = MLP([h_i^\top, o_t^\top])
$$

最后只在被 mask 的 token 上计算预测损失：

$$
L_i = \sum_{t=1}^{n_i} \mathbf 1(T'_t=[MASK]) \log Pr(T_t|z_t)
$$

这意味着：  
**token 预测不是只靠文本上下文，而是显式融合了该节点的邻居结构信息。**



这一步的直觉很强：  
对于 TAG，一个 token 的恢复不仅取决于本句语义，还可能取决于图中邻居节点提供的语义背景。P2TAG 就把这两者联合了起来。图 1 上半部分就是这个流程：LM 编码文本，GNN 在 mini-batch 图上聚合，再回到 MLM 预测。



---

### 2.3 Mini-batch 训练：为什么用 GraphSAINT

因为 LM 很重，无法在整图上直接训练，所以 P2TAG 采用 **GraphSAINT** 做子图采样。  
而且他们选的是 **random-walk sampler**，目的是尽量保留原图连通性。



采样过程是：

-   随机选 $r$ 个 root nodes
    
-   每个 root 做长度为 $l$ 的随机游走
    
-   把所有游走经过的节点收集成 $V_s$
    
-   由 $V_s$ 诱导出的子图 $G_s$ 作为一个 mini-batch。
    
    
    

这样每个训练 step 实际在一个 sampled subgraph 上完成：

1.  对子图内节点文本做 masking
    
2.  LM 编码文本
    
3.  GNN 在 sampled subgraph 上传播
    
4.  用 MLM loss 训练。
    
    
    

你可以把这理解成：

**GraphSAINT 解决算力问题，MLM 解决预训练目标问题，LM+GNN 联合则解决文本与结构融合问题。**

---

## 3\. 第二阶段：Graph-Text Mixed Prompt Learning

这部分是论文最核心的创新。  
作者认为 few-shot 下不能全量微调预训练模型，所以要走 prompt learning 路线。但在 TAG 上 prompt 设计特别难，因为要同时考虑：

-   LM 侧的文本信息
    
-   GNN 侧的结构信息。
    
    
    

所以他们提出的是 **mixed prompt**，由两部分组成：

1.  **graph prompt**
    
2.  **text prompt**。
    
    
    

而且这两部分是配合使用的，不是二选一。

---

### 3.1 先构造 ego graph

对目标节点 $v$，先取最多 100 个一阶邻居，加上节点本身，形成 ego node set $V_{ego}$，再诱导出 ego graph $G_{ego}$。  
后面的 prompt learning 就是在这个局部子图上进行。



这说明 P2TAG 不是对全图直接做 prompt，而是针对每个目标节点构一个局部图视角来分类。

---

## 4\. Graph prompt：造一个小型 prompt graph 接到 ego graph 上

作者借鉴 graph prompt 文献，为每个目标节点额外构造一个 **prompt graph** $G_p=(V_p,E_p)$。  
它相当于是一个小型可学习图，作为辅助结构接到 ego graph 上。



### 4.1 prompt graph 内部边怎么建

设 prompt graph 里第 $i,j$ 个 token 的特征分别是 $p_i,p_j$，内部连边由相似度阈值决定：

$$
A_{G_p}(i,j)= \begin{cases} 1 & \text{if } Sim(p_i,p_j)\ge \sigma_{inner}\\ 0 & \text{otherwise} \end{cases}
$$

这里相似度用的是 dot product。



### 4.2 prompt graph 和 ego graph 之间怎么连

设 ego graph 中第 $k$ 个节点特征为 $x_k$，则它和 prompt token $p_j$ 的连边定义为：

$$
A_{G_{ego},G_p}(k,j)= \begin{cases} 1 & \text{if } Sim(x_k,p_j)\ge \sigma_{inter}\\ 0 & \text{otherwise} \end{cases}
$$

也就是说，prompt token 既能彼此连边，也能和原 ego graph 节点连边。



所以 graph prompt 不是简单“加几个向量”，而是真正构了一个可学习的小图，并插入到目标节点的局部子图里。

---

### 4.3 为什么要用标签文本初始化 graph prompt

作者发现，直接随机造一个 prompt graph 效果并不好。  
他们的解释是：P2TAG 的预训练任务是 **masked token prediction**，这和很多 graph prompt 论文里的 pretext（例如 link prediction）不一样。  
既然预训练阶段模型已经习惯把输入对齐到一个“预训练标签空间”，那么下游 prompt 更应该做的是：**把目标节点往下游标签空间方向稍微推过去。**



因此他们不用手工文本模板，而是直接用 **label text embeddings** 初始化 prompt graph。  
如果下游是 $N$\-way 分类，类别文本分别记作 $s_{y_i}$，则第 $i$ 个 prompt token 初始化为：

$$
p_i^{(0)}= \begin{cases} f_{LM}(s_{y_i}) & i\le N\\ \text{Random Initialization} & \text{otherwise} \end{cases}
$$

也就是：

-   前 $N$ 个 prompt tokens 用类别文本编码初始化
    
-   多出来的 token 再随机初始化。
    
    
    

作者在第 5 页 Figure 2 专门画了这个思想：  
不是用传统文本 prompt 去硬写模板，而是直接把“Animals”“Science Fiction and Fantasy”这类 label text 编码成 prompt tokens，再插入图里，使目标节点更靠近下游 label space。



这一点其实是 P2TAG 很巧的地方：  
**它把下游标签文本变成 graph prompt 的初始化锚点。**

---

## 5\. Text prompt：不用复杂模板，直接学一个“LM 输出提示向量”

除了 graph prompt，作者还设计了一个很轻量的 **text prompt**。

因为在预训练阶段，最终用于 MLM 预测的是：

-   LM token output
    
-   加上 GNN 聚合后的节点表示
    

两者拼起来再进 MLP。  
所以下游阶段，他们也希望延续这个“文本 + 结构联合”的形式。



但作者没有再去造复杂自然语言模板，而是直接定义一个可训练向量：

$$
w_t \in \mathbb R^{1\times d}
$$

把它看成 LM 输出侧的 prompt。初始化方式也很简单：

$$
w_t^{0} = f_{LM}(s_v)
$$

即用目标节点自己的文本编码来初始化。



你可以把它理解成：

**graph prompt 负责补结构侧的提示，text prompt 负责补文本侧的提示。**

---

## 6\. 最终提示学习前向过程

把 graph prompt 和 text prompt 合起来后，P2TAG 的 few-shot 前向函数写成：

$$
\tilde z_v = MLP(READOUT(f_{GNN}(G_v;G_p)), w_t)
$$

含义是：

1.  先在目标节点的 ego graph 上插入 prompt graph
    
2.  用固定的预训练 GNN 得到该 prompted graph 的图表示
    
3.  再把这个图表示和 text prompt $w_t$ 一起送入 MLP
    
4.  输出最终分类表示。
    
    
    

这里要注意：在 prompt learning 阶段，

-   $f_{LM}$ 和 $f_{GNN}$ **都是冻结的**
    
-   真正训练的是
    
    -   prompt graph $G_p$
        
    -   text prompt $w_t$
        
    -   task head（MLP）。
        
        
        

所以这就是典型的 prompt tuning，而不是 full fine-tuning。

---

## 7\. 推理阶段的三种用法

论文最后给了三种 inference 方式：

### P2TAG (LM)

只用预训练 LM，对所有节点文本做 mini-batch 编码，取 `[CLS]` 向量作为节点表示。



### P2TAG (GNN)

先得到所有节点的 `[CLS]` 向量，再送入 GNN 做图传播，得到节点表示。  
测试时不用随机采样，而是改成 **full neighbor sampling**，避免训练时子图采样带来的随机性。



### P2TAG

在 P2TAG (GNN) 基础上，再加上 mixed prompt 做 few-shot 分类。  
最终实验里，完整的 P2TAG 通常最好。



---

## 8\. 这篇方法为什么有效

从论文方法设计看，我觉得它的优势主要有三点。

### 第一，预训练阶段更贴近 TAG 本质

不是先把文本压成静态向量再处理，而是直接对原始文本和图结构联合做自监督。  
而且 MLM 是个难任务，能缓解大 LM + 小 GNN 联训时的过拟合问题。



### 第二，prompt 同时考虑文本和图

已有方法大多偏文字侧或图侧。P2TAG 则把：

-   label-text initialized graph prompt
    
-   node-text initialized text prompt
    

一起用，这就是它所谓 **mixed prompt**。



### 第三，label text initialization 很自然

因为 few-shot 分类本来就要把节点往下游标签空间映射。  
直接用 label text 初始化 graph prompt，比手工写 prompt 模板更直接，也更符合 TAG 的语义特点。



---

## 9\. 方法效果验证

论文实验里，完整 P2TAG 在六个 TAG 数据集上，相比 meta-learning 方法平均提升 **+18.98% 到 +35.98%**。  
相比 GIANT、G2P2 这类也利用原始文本的方法，P2TAG 依然更强。  
而且在 ogbn-products 这种大图上，G2P2 预训练超过 30 天，P2TAG 联合训练不到 1 天。



另外，第 8 页 Figure 3 的消融还表明：

-   去掉 graph prompt 初始化（w/o $P_G$）
    
-   去掉 text prompt（w/o $w_t$）  
    都会掉点，而且 **graph prompt 初始化的影响更大一些**，说明结构侧提示在 TAG 上确实很关键。

---

## 10\. 一句话总结

**P2TAG 的方法就是：在文本属性图上，用 masked language modeling 把 LM 和 GNN 联合预训练起来，让 `[CLS]` 节点表示在图上传播并参与 token 恢复；到了 few-shot 下游阶段，再为每个目标节点构造 ego graph，接入一个由 label text 初始化的小型 prompt graph，同时加入一个由目标节点文本初始化的 text prompt，最后在冻结的 LM 和 GNN 上只训练 prompts 和轻量任务头，从而同时利用文本语义和图结构完成 few-shot 节点分类。**
