
这篇 **Self-Pro** 的方法，核心可以概括成一句话：

**先用适合同配/异配图的非对称图对比学习做预训练，再把预训练任务和下游任务统一改写成“token 两两相似度”模板，最后复用预训练里的 projector 当作下游适配器，并从图本身注入结构 prompt 和语义 prompt 来做高效迁移。** 它的目标是同时解决四个问题：异配图泛化差、pretext 与 downstream 目标不一致、下游调参开销大、以及现有 graph prompt 过度依赖随机初始化。



整套方法可以分成四块看：

1.  **预训练：用 GraphACL 做非对称图对比学习**
    
2.  **统一模板：把预训练、节点分类、链路预测都改成 pairwise similarity**
    
3.  **自适配器：复用预训练 projector，而不是新加下游头**
    
4.  **自提示：从图自身构造结构 prompt 和语义 prompt，再做 prompt tuning**。


---

### 1\. 预训练：为什么选 GraphACL

作者先指出，很多图预训练方法默认或隐含遵循 **homophily**，所以在 heterophily 图上泛化不好。为了解决这个问题，Self-Pro 选了 **Graph Asymmetric Contrastive Learning（GraphACL）** 作为预训练骨干。Figure 2 的上半部分就是这个流程：encoder 输出表示，projector 输出对比空间 token，再计算相似度损失。

GraphACL 的关键不是普通对称对比，而是**非对称结构**。  
对节点 $v$ 和其正样本 $v^+$，损失写成：

$$
L = -\frac{1}{|V|}\sum_{v\in V}\frac{1}{|N(v)|}\sum_{v^+\in N(v)} \log \frac{\exp(z_v^\top h_{v^+}/\tau)} {\exp(z_v^\top h_{v^+}/\tau)+\sum_{v^-\in V^-}\exp(h_v^\top h_{v^-}/\tau)}
$$

其中：

-   $h_v$ 是 encoder 输出的表示
    
-   $z_v=g(h_v)$ 是 projector 输出的表示
    
-   正样本来自邻居集合 $N(v)$
    
-   负样本随机采样。
    
    
    

和普通 GCL 的区别在于：  
**anchor 侧经过 projector，neighbor 侧直接用 encoder 表示**，形成非对称对比。作者认为这种设计能捕获更高阶邻居相似性，不会像传统同配式平滑那样把“邻居必须相似”硬编码得太死，因此更适合 heterophily 图。论文里也明确说，projector 的设计允许邻居节点拥有不同表示，并且 GraphACL 已被证明可以建模超越局部同配的复杂模式。



还有一点很重要：Self-Pro 不是把 projector 当作预训练阶段的临时部件，而是认为它**保留了重要的预训练知识**，不应该像很多 GCL 方法那样预训练完就丢掉。后面它会被直接复用到下游。

### 2\. 统一模板：把 pretext 和 downstream 都写成“token 相似度”

Self-Pro 的第二个关键点，是把预训练和下游任务统一到同一个 prompt template 里。作者借鉴 NLP prompt 的思想，认为如果 pretext 和 downstream 目标不一致，就会出现 negative transfer。所以他们定义了一个统一模板：

$$
p(v)=sim(t_v,t_t)
$$

其中：

-   $t_v$ 是节点 $v$ 的 token
    
-   $t_t$ 是目标 token
    
-   $sim(\cdot)$ 可以是 dot product 或 cosine similarity。
    
    
    

这个模板下，三种任务都能统一：

**第一类，预训练任务。**  
目标 token 就是正样本或负样本节点的 token，本质上仍然是“让正样本更近、负样本更远”。这和 GraphACL 的对比目标完全一致。



**第二类，链路预测。**  
目标 token 设为相邻节点或不相邻节点的 token，于是链路预测也变成 pairwise similarity 判别：  
相邻边两端相似度大，非相邻节点相似度小。



**第三类，节点分类。**  
这里作者不直接用 one-hot 分类头，而是给每个类别构造一个 **class prototype token**。  
对第 $c$ 类，其 prototype 初始化为该类已标注节点 token 的均值：

$$
t_c=\frac{1}{N_c}\sum_{v\in V_L,y_v=c} t_v
$$

于是节点分类就变成：

-   节点和**本类 prototype**相似度要大
    
-   节点和**其他类 prototype**相似度要小。
    
    
    

这个改写非常关键，因为它把：

-   pre-training 的对比学习
    
-   downstream 的 node classification
    
-   downstream 的 link prediction
    

统一到了同一个“**两两相似度**”模板里。这样就缓解了论文一开始提到的目标不匹配问题。

### 3\. 自适配器：为什么要复用 projector

很多图预训练方法到了下游，会：

-   丢掉 projector
    
-   新接一个 classifier 训练。
    

Self-Pro 认为这样做浪费了预训练学到的知识，因为在 GraphACL 里，**projector 本身承担了建模高阶上下文与局部分布的作用**。所以它直接把 projector 拿来当下游的 **self adapter**。



形式上，预训练阶段优化：

$$
\theta^*,\phi^*=\arg\min_{\theta,\phi}L_{pre}(f_\theta,g_\phi,G)
$$

其中 $f_\theta$ 是 encoder，$g_\phi$ 是 projector。



到了下游阶段：

-   **冻结 encoder $f_\theta$**
    
-   只优化初始化自预训练 projector 的 $g_\phi$。
    

目标写成：

$$
\phi^{**}=\arg\min_{\phi^*}L_{dow}(g_{\phi^*},V_L,Y)
$$

也就是说，Self-Pro 不额外加一个复杂的下游网络，而是直接把预训练 projector 平滑迁移成下游 adapter。作者认为这样有两个好处：

1.  保留 pre-training 阶段已经学到的知识
    
2.  tuning 成本低，因为只调 projector，不调整个 encoder。
    
    
    

这也是为什么论文把它叫 **self adapter**：  
它不是新造一个下游模块，而是“从模型自身拿一个部件出来继续用”。

### 4\. 自提示：不用随机 prompt，而从图自身找 prompt

这是 Self-Pro 最有特点的部分。作者批评现有 graph prompt 大多用随机初始化的虚拟向量、虚拟节点或虚拟图，稳定性差，也难解释。于是 Self-Pro 从图自身的两种信息源出发做 prompt：

-   **结构信息**
    
-   **语义信息**。
    
    
    

#### 4.1 Self structural prompt

从结构角度，作者认为多跳邻居很重要，特别是在很多同配图里，两跳邻居常常也共享标签。因此他们直接把 **two-hop 邻居图** 作为结构 prompt。  
做法是：从原图 $G$ 构造 2-hop 图 $G_2$，对应邻接矩阵 $A_2$。若存在路径 $i\to j\to k$，则 $(A_2)_{ik}=1$。然后把这个两跳图送进冻结的 encoder：

$$
t_v=f_\theta(G_2)[v]=f_\theta(A_2,X)[v]
$$

得到用于下游 tuning 的 node token。



直观上，这等于告诉模型：

**除了原来的一跳局部结构，再给你一个“二跳邻域视角”作为提示。**

论文也承认，还可以用更复杂的结构学习方法做 structural prompt，但他们实现里为了简单，直接采用 two-hop 邻居注入。



#### 4.2 Self semantic prompt

对于 heterophily 图，结构不一定可靠，节点特征语义反而更重要。  
因此作者又设计了 **semantic prompt**。做法很巧妙：直接把邻接矩阵 $A$ 换成单位阵 $I$，构造一个“只有自环、没有邻居传播”的图 $G_I$，再送进冻结 encoder：

$$
s_v=f_\theta(G_I)[v]=f_\theta(I,X)[v]
$$

这样得到的 $s_v$ 尽可能保留节点自己的语义，而不被邻居结构干扰。



同时，原图上的上下文表示记为：

$$
h_v=f_\theta(G)[v]=f_\theta(A,X)[v]
$$

然后作者把 semantic prompt $s_v$ 和上下文表示 $h_v$ 融合，形成最终用于 tuning 的 token。论文给了两种注入方式：

一种是固定权重：

$$
t_v=\mu s_v + (1-\mu)h_v
$$

另一种是自适应权重：

$$
t_v=w_v s_v+(1-w_v)h_v,\quad w_v=sim(h_v,s_v)
$$

也就是根据节点自身“语义视角”和“上下文视角”的相似度，自动决定融合比例。



这个设计很有意思：

-   同配图上，$h_v$ 往往更有用
    
-   异配图上，$s_v$ 往往更重要。
    

所以 semantic prompt 其实是给模型一个“退回节点自身语义”的通道。论文后面的实验也确实发现：同配图更受益于 structural prompt，而某些异配图更受益于 semantic prompt。

### 5\. Prompt tuning：在统一模板下做下游优化

有了 prompt 注入后的 $t_v$，Self-Pro 再通过 self adapter（也就是 projector）做整合，得到：

$$
t'_v = g_\phi(t_v)
$$

然后下游任务仍然沿用前面定义的统一相似度模板。

#### 节点分类

对已标注节点 $v$，与其本类 prototype $t'_{y_v}$ 做正对比，与其他类 prototype 做负对比：

$$
L_{dow}= -\sum_{v\in V_L} \log \frac{\exp(t_v'^T t_{y_v}'/\tau)} {\exp(t_v'^T t_{y_v}'/\tau)+\sum_{c\neq y_v}\exp(t_v'^T t_c'/\tau)}
$$

最终预测时，哪个类 prototype 最近，就判成哪一类。



#### 链路预测

随机采一个正邻居 $a$ 和一个负样本 $b$，形成 triplet $(v,a,b)$，损失为：

$$
L_{dow}= -\sum_{(v,a,b)\in T} \log \frac{\exp(t_v'^T t_a'/\tau)} {\exp(t_v'^T t_a'/\tau)+\exp(t_v'^T t_b'/\tau)}
$$

所以 link prediction 也仍然是统一的 pairwise similarity 学习。



你会发现，Self-Pro 下游阶段没有重新发明一个复杂任务头，而是：

-   prompt 注入
    
-   projector 适配
    
-   pairwise similarity 优化
    

整个流程都跟预训练模板保持一致。

### 6\. 这篇方法为什么成立

如果把整篇论文的方法逻辑压缩一下，可以概括成：

#### 第一层：解决 heterophily 预训练问题

选 **GraphACL** 做预训练，因为它的非对称 projector 设计能建模高阶邻居关系，不像普通对比学习那样死守 homophily。



#### 第二层：解决 pretext 与 downstream 的目标错位

把 pre-training、node classification、link prediction 全都改写成 **token 相似度模板**，缓解 negative transfer。



#### 第三层：解决 tuning 开销和 prompt 不稳定

不重新加大头，只复用 projector 做 self adapter；  
不再随机学 prompt，而是从图自身抽取 **结构 prompt** 和 **语义 prompt**。



所以 Self-Pro 的“Self”主要体现在两个地方：

-   **self adapter**：模型自己预训练时的 projector 被拿来复用
    
-   **self prompt**：prompt 来自图自己，而不是外加随机虚拟参数。

---

### 7\. 一句话总结

**Self-Pro 先用适用于同配/异配图的非对称图对比学习 GraphACL 预训练 GNN，把预训练与下游节点分类/链路预测统一到“token 两两相似度”的模板下；随后冻结 encoder、复用预训练 projector 作为 self adapter，再从图本身注入 two-hop structural prompt 或 identity-graph semantic prompt，最后通过 prototype-based similarity loss 做高效下游 tuning。**
