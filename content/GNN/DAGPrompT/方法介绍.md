这篇 **DAGPrompT** 的方法，核心可以先概括成一句话：

**它不是像传统 graph prompting 那样把预训练 GNN 完全冻结，只靠一个简单 prompt 去适配下游，而是同时做两件事：一边用低秩方式轻量调整 GNN 编码器去适应下游分布，一边按不同 hop 单独做 prompting，再把各 hop 的结果自适应融合。** 论文把这两部分分别叫做 **GLoRA** 和 **Hop-specific Graph Prompting**。



这篇论文主要想解决的是，现有 graph prompting 在**复杂分布图**上尤其是 **heterophily 图**上效果不佳的问题。作者认为根源有两个。  
第一，预训练任务和下游任务存在分布与目标差异，尤其在 heterophily 图里，相连节点可能标签不同，但很多预训练方法例如 link prediction 会把相连节点压到相近表示，导致下游难区分。此时如果 GNN encoder 再被冻结，就更难适配新分布。  
第二，不同节点对不同 hop 的依赖并不一样，而且不同 hop 上的异配/同配分布也不同，现有 prompting 方法大多只用最后一层表示，或者简单拼接中间层，不能针对 hop 差异定制 prompt。



所以 DAGPrompT 的整体框架分两阶段，图 3 画得很清楚：  
先做 **link-prediction based pre-training**；  
然后在下游做 **Graph Low-rank Adaptation + Hop-specific Graph Prompting**。

### 1\. 预训练阶段：先用 link prediction 学一个通用 GNN encoder

作者先选 **link prediction** 做 label-free pre-training。原因有两个：

1.  图里天然就有大量边，容易构造自监督样本；
    
2.  节点分类、图分类等下游任务都可以被改写成“与 pseudo-node / pseudo-graph 之间的 link prediction”，所以形式上更容易和下游对齐。
    
    
    

具体做法是：  
对图里一个节点 $v$，从它的邻居里采一个正样本 $a$，从非邻居里采一个负样本 $b$，形成三元组 $(v,a,b)$。GNN encoder $f$ 输出它们的表示 $s_v,s_a,s_b$，然后用对比式损失让：

-   $s_v$ 和 $s_a$ 更接近
    
-   $s_v$ 和 $s_b$ 更远。
    
    
    

损失写成：

$$
L_{pt}(\Theta)=- \sum_{(v,a,b)\in T} \ln \frac{\exp(\text{sim}(s_v,s_a)/\tau)} {\sum_{u\in\{a,b\}}\exp(\text{sim}(s_v,s_u)/\tau)}
$$

其中 $\tau$ 是 temperature。



这一步学到的是一个预训练 GNN encoder，但作者认为：**仅靠后续冻结 encoder + 普通 prompting，不足以应对 heterophily 和 hop 分布变化。**

---

### 2\. 第一核心模块：GLoRA

这是 DAGPrompT 的第一根主线。  
作者认为，传统 prompting 方法在下游阶段通常完全冻结 encoder，这在 homophily 图上还行，但在 heterophily 图上会出问题：预训练时学到的“连边节点更像”这一偏好，可能和真实标签结构冲突。如果不允许 encoder 适配，下游 prompt 再怎么调，也很难把不同标签节点真正拉开。



但作者又不想直接 full fine-tune，因为 few-shot 下全参数调优容易：

-   计算开销大
    
-   过拟合
    
-   破坏预训练知识。
    
    
    

所以他们借鉴 NLP 里的 LoRA，提出 **Graph Low-Rank Adaptation (GLoRA)**。  
GLoRA 不是全改参数，而是只对 GNN layer 里两部分做低秩适配：

1.  **projection matrix**
    
2.  **message-passing scheme**。
    
    
    

论文给出的第 $l$ 层更新公式是：

$$
H^{(l)}= \left(A+P_A^{(l)}Q_A^{(l)\top}\right) H^{(l-1)} \left(W_0^{(l)}+P^{(l)}Q^{(l)\top}\right)
$$

这里：

-   $W_0^{(l)}$ 是预训练好的、被冻结的原始参数；
    
-   $P^{(l)},Q^{(l)}\in\mathbb R^{d\times r}$ 是投影矩阵的低秩增量；
    
-   $P_A^{(l)},Q_A^{(l)}\in\mathbb R^{N\times 1}$ 是 message-passing 侧的低秩增量。
    
    
    

你可以把它理解成两层调节：

#### 一层是“调投影”

即在原始线性变换 $W_0^{(l)}$ 外面，加一个低秩修正 $P^{(l)}Q^{(l)\top}$。  
这样模型能轻量地调整表示空间，但大部分预训练知识仍保留在 $W_0^{(l)}$ 中。



#### 一层是“调消息传播”

即不直接改原始邻接矩阵 $A$，而是在 message passing 侧加一个低秩修正 $P_A^{(l)}Q_A^{(l)\top}$。  
这等于允许模型稍微改变“哪些邻接关系更该被强调”，从而适应下游分布。对于 heterophily 图，这尤其重要，因为原始连边未必意味着语义相近。



所以 GLoRA 的本质不是单纯参数压缩，而是：

**用极少的新参数，给冻结 encoder 一点“重新解释下游图分布”的能力。**

论文后面的理论分析也在强调这一点：few-shot 下全参数 fine-tune 复杂度高、泛化边界差；完全冻结又容易欠拟合；GLoRA 刚好在“灵活性”和“复杂度”之间折中。

### 3\. 第二核心模块：Hop-specific Graph Prompting

这是 DAGPrompT 的第二根主线。

作者认为，即使 encoder 可以轻量适配，现有 prompting 方法依然有另一个结构性问题：**它们往往只看最后一层表示，或者粗暴合并中间层，没有显式考虑不同 hop 的信息分布差异。**  
但在复杂图里，不同 hop 常常承担不同语义。例如在某些 heterophily 图中，一跳邻居可能高度异配，二跳反而变成同配。如果你只拿最后一层或统一融合，很容易把这些差异抹平。



所以作者做了一个 hop-decoupled 的 prompting。

#### 3.1 先统一下游任务

他们先把不同下游任务都统一成 link prediction 视角：

-   **Link prediction**：直接比较节点之间是否更应连边；
    
-   **Node classification**：为每个类别构造一个 pseudo-node，节点分类就变成“这个节点最可能和哪个 pseudo-node 连边”；
    
-   **Graph classification**：为每个类别构造一个 pseudo-graph，图分类变成“这个图最可能和哪个 pseudo-graph 连边”。
    
    
    

这一步和 GPPT/GraphPrompt 一脉相承，本质上是为了让下游形式继续和 link-prediction pre-training 对齐。



#### 3.2 收集每一层的中间表示

不是只用最后一层 $H^{(L)}$，而是把所有层都收集起来：

$$
H= \big[H^{(0)}\|H^{(1)}\|\cdots\|H^{(L)}\big]
$$

其中 $H^{(0)}=\text{Linear}(X)$。  
每一层可以理解成对应一个 hop 级别的语义。



#### 3.3 为每一层单独构造 class prompts

作者不是只做一组 class token，而是对每层都做一组 **Layer-specific Class Prompts**：

$$
P= \big[P^{(0)}\|P^{(1)}\|\cdots\|P^{(L)}\big]
$$

其中第 $l$ 层第 $c$ 类的 prompt 是：

$$
P_c^{(l)}= \frac{1}{|D_c^{train}|} \sum_{v\in D_c^{train}} H_v^{(l)} + \Theta_c^{(l)}
$$

也就是说，它由两部分构成：

-   第 $l$ 层上该类训练样本的平均表示
    
-   一个可学习的 layer-specific prompt $\Theta_c^{(l)}$。
    
    
    

这一步很关键。它意味着：

**不同 hop 上，不同类别都有自己专门的 prompt 原型。**

所以 DAGPrompT 不是在整个网络上只放一套 prompt，而是每个 hop 都维护一套类提示。



#### 3.4 每个 hop 单独做 similarity prompting

对每层 $l$，都计算节点表示与该层类 prompt 的相似度：

$$
S^{(l)}=\text{Sim}(H^{(l)},P^{(l)})
$$

论文里用的是 cosine similarity。



这意味着模型会在每个 hop 上分别问一遍：

-   从 0-hop 视角看，这个样本像哪个类？
    
-   从 1-hop 视角看，它像哪个类？
    
-   …
    
-   从 $L$\-hop 视角看，它像哪个类？
    
    
    

#### 3.5 再用可学习系数融合各 hop

最后不是简单平均，而是用一组可学习系数 $\gamma^{(l)}$ 把每层结果加权：

$$
\tilde S = \sum_{l=1}^{L}\gamma^{(l)} S^{(l)}, \qquad \hat Y = \arg\max_c \tilde S_c
$$

初始时 $\gamma^{(l)}$ 用一个衰减形式初始化，由超参数 $\alpha$ 控制近邻和远邻的相对重要性；训练时再让模型自己调整。



所以 Hop-specific Graph Prompting 的本质是：

**不再假设“最后一层表示最好”或“所有层一样重要”，而是让模型自己决定每个 hop 对当前任务有多重要。**

---

### 4\. 下游优化目标

在 prompting 阶段，作者对所有层都做一个温度缩放的对比式分类损失：

$$
L_{ds}= - \sum_{l=0}^{L} \sum_{(x_i,y_i)\in D_{train}} \log \frac{ \exp(\text{Sim}(H_{x_i}^{(l)},P_{y_i}^{(l)})/\tau) }{ \sum_{c=1}^{C} \exp(\text{Sim}(H_{x_i}^{(l)},P_c^{(l)})/\tau) }
$$

这说明：

-   每一层都要学会把样本拉向对应类别的 layer-specific prompt
    
-   同时远离其它类别 prompt。
    
    
    

结合前面的 GLoRA，训练时更新的是：

-   GLoRA 的低秩参数
    
-   各层的 learnable prompts $\Theta^{(l)}$
    
-   hop 融合系数 $\gamma^{(l)}$
    

而原始预训练权重大部分保持冻结。



---

### 5\. 这篇方法为什么能解决 heterophily 下的问题

我觉得论文的方法论逻辑很清晰，可以分两层看。

#### 第一层：GLoRA 解决“冻结 encoder 无法适配新分布”

heterophily 图里，原始预训练 encoder 往往倾向于把相连节点拉近，但这可能与标签结构冲突。  
GLoRA 允许 encoder 在 message passing 和 projection 两端轻量调整，所以能把“connected but different label”的节点重新拉开一些。



#### 第二层：Hop-specific prompting 解决“不同 hop 的分布不一样”

heterophily 往往不是全局统一的。有些节点依赖近邻，有些依赖远邻；一跳异配、二跳同配的情况也很多。  
所以必须让不同 hop 有不同 class prompts，并让模型自己学习融合权重，而不是只盯最后一层。



换句话说：

-   **GLoRA** 解决 encoder 适配问题
    
-   **Hop-specific Prompting** 解决 prompt 粒度问题。
    
    
    

---

### 6\. 和已有 graph prompting 方法的区别

和前面那些方法相比，DAGPrompT 有两个特别鲜明的区别。

第一，它不再坚持“冻结 encoder 才是 prompting”。  
很多 graph prompting 方法默认 prompt tuning 应该只调 prompt，不碰 encoder。DAGPrompT 认为在 heterophily 图上这太僵硬，所以引入了 GLoRA，在不做 full fine-tune 的前提下给 encoder 最小必要的可调性。



第二，它不再把 prompt 视为单层、单尺度的东西。  
很多方法只做一套 class token / prompt vector，而 DAGPrompT 是每层单独做 prompt，再用 learnable hop coefficients 融合，因此更适合复杂图分布。



所以它并不是简单改进某个 prompt 形式，而是从两个方面一起推：

-   **distribution-aware encoder adaptation**
    
-   **distribution-aware hop prompting**。
    
    
    

---

### 7\. 一句话总结

**DAGPrompT 先用 link prediction 预训练 GNN，再在下游阶段通过 GLoRA 对消息传播和投影矩阵做低秩适配，使 encoder 能轻量跟随新分布；同时构造 hop-specific class prompts，在每一层单独做 similarity-based prompting，并用可学习系数融合不同 hop 的结果，从而把 graph prompting 从 homophily 场景扩展到更复杂的 heterophily 图。**
