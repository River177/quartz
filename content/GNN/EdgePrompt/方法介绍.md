这篇论文提出的方法叫 **EdgePrompt / EdgePrompt+**，核心思想是：

> 以前的图提示学习大多在“节点特征”或“节点表示”上加 prompt；这篇论文认为边在 GNN 消息传递中同样关键，因此把 prompt 加到 **边上**，让预训练 GNN 在下游任务中通过“边级提示”更好地调整消息传递过程。
> 
> 

---

## 1\. 问题背景：为什么要做 Edge Prompt？

图预训练通常先用无标签图数据训练一个 GNN，然后迁移到下游任务，例如：

-   预训练任务：边预测、图对比学习、节点特征重建；
    
-   下游任务：节点分类、图分类。
    

但是这两者目标不一致，会产生 **objective gap**。

已有 graph prompt tuning 方法一般冻结预训练 GNN，只学习少量 prompt 参数。但它们大多有一个特点：prompt 主要加在 **节点特征** 或 **节点表示** 上，例如：

$$
x_i' = x_i + p_i
$$

这类方法的问题是：节点上的 prompt 会在 GNN 消息传递中被均匀传给所有邻居。

举例来说，节点 $v_1$ 有两个邻居 $v_2$ 和 $v_3$，如果给 $v_1$ 加一个节点 prompt $p_1$，那么 $v_2$ 和 $v_3$ 都会收到同一个 $p_1$。但在真实图中，不同边代表不同关系，同一个节点传给不同邻居的信息不应该完全一样。

所以论文提出：

> 不在节点上加 prompt，而是在边上加 prompt，让不同边拥有不同的可学习提示信息。

论文图 1 就是在说明这个区别：节点 prompt 会被统一传播，而边 prompt 可以针对不同边进行定制化传播。



---

# 2\. 基础 GNN 消息传递

普通 GNN 第 $l$ 层的消息传递可以写成：

$$
h_i^{(l)} = COMB^{(l)} \left( h_i^{(l-1)}, AGG^{(l)}(\{h_j^{(l-1)}: v_j \in \mathcal{N}(v_i)\}) \right)
$$

含义是：

-   $h_i^{(l)}$：节点 $v_i$ 在第 $l$ 层的表示；
    
-   $\mathcal{N}(v_i)$：节点 $v_i$ 的邻居；
    
-   $AGG$：聚合邻居信息；
    
-   $COMB$：融合自身表示和邻居聚合结果。
    

普通 GNN 聚合的是邻居节点表示 $h_j^{(l-1)}$，而 EdgePrompt 的做法是：在聚合邻居节点表示的同时，也聚合边上的 prompt 向量。

---

# 3\. EdgePrompt：给所有边共享一个 prompt 向量

EdgePrompt 是论文提出的基础版本。

对于每条边 $(v_i, v_j)$，在第 $l$ 层引入一个边 prompt：

$$
e_{ij}^{(l)} \in \mathbb{R}^{D_{l-1}}
$$

然后修改 GNN 的消息传递过程：

$$
h_i^{(l)} = COMB^{(l)} \left( h_i^{(l-1)}, AGG^{(l)} ( \{h_j^{(l-1)}: v_j \in \mathcal{N}(v_i)\}, \{e_{ij}^{(l)}: v_j \in \mathcal{N}(v_i)\} ) \right)
$$

也就是说，节点 $v_i$ 在聚合邻居 $v_j$ 的信息时，不仅看邻居表示 $h_j^{(l-1)}$，还会看边 $(v_i,v_j)$ 上的 prompt 向量 $e_{ij}^{(l)}$。

---

## EdgePrompt 的简单实现

基础版 EdgePrompt 让所有边共享同一个 prompt 向量：

$$
e_{ij}^{(l)} = p^{(l)}, \quad \forall (v_i, v_j) \in E
$$

其中：

-   $p^{(l)}$ 是第 $l$ 层的全局边 prompt；
    
-   每一层有一个自己的边 prompt；
    
-   所有边在同一层共享这个 prompt。
    

因此，如果预训练 GNN 有 $L$ 层，那么 EdgePrompt 学习的是：

$$
\{p^{(1)}, p^{(2)}, ..., p^{(L)}\}
$$

这种设计的优点是：

1.  参数量小；
    
2.  适配不同大小的图；
    
3.  不依赖具体预训练任务；
    
4.  可以用于 GCN、GIN 等原本不支持 edge attributes 的 GNN。
    

但是它也有明显不足：所有边共享同一个 prompt，表达能力有限。

所以论文进一步提出 **EdgePrompt+**。

---

# 4\. EdgePrompt+：每条边学习定制化 prompt

EdgePrompt+ 是本文更重要的版本。

它的目标是：

> 不同边应该有不同的 prompt，因为不同边连接的节点关系不同。

最直接的做法是给每条边独立学习一个 prompt：

$$
e_{ij}^{(l)}
$$

但这样会有两个问题：

1.  边太多，参数量巨大；
    
2.  下游任务往往是 few-shot，很多边接触不到监督信号，无法有效学习。
    

所以论文没有让每条边独立拥有自由参数，而是设计了 **anchor prompts**。

---

## 4.1 Anchor Prompts

在第 $l$ 层，设置 $M_l$ 个可学习的 anchor prompt：

$$
P^{(l)} = \{p_1^{(l)}, p_2^{(l)}, ..., p_{M_l}^{(l)}\}
$$

每个 anchor prompt 是一个向量：

$$
p_m^{(l)} \in \mathbb{R}^{D_{l-1}}
$$

然后每条边的 prompt 不是直接学习，而是由这些 anchor prompts 加权组合得到：

$$
e_{ij}^{(l)} = \sum_{m=1}^{M_l} b_{ijm}^{(l)} p_m^{(l)}
$$

其中：

-   $b_{ijm}^{(l)}$ 是边 $(v_i,v_j)$ 对第 $m$ 个 anchor prompt 的权重；
    
-   所有权重组成一个向量：
    

$$
b_{ij}^{(l)} \in \mathbb{R}^{M_l}
$$

这样，每条边都有自己的 prompt，但它是由共享的 anchor prompt 组合出来的。

这有点像：

> 所有边共享一组“基础提示模板”，每条边根据自身两端节点关系，选择不同的组合方式。

---

## 4.2 如何计算边的权重 $b_{ij}^{(l)}$？

EdgePrompt+ 用一个打分函数 $\phi^{(l)}$ 来计算边 $(v_i,v_j)$ 的权重。

论文采用类似 GAT 的注意力机制：

$$
\phi^{(l)}(v_i, v_j) = LeakyReLU([h_i^{(l-1)} || h_j^{(l-1)}] W^{(l)})
$$

其中：

-   $[h_i^{(l-1)} || h_j^{(l-1)}]$：把两个节点上一层的表示拼接；
    
-   $W^{(l)} \in \mathbb{R}^{2D_{l-1} \times M_l}$：可学习参数；
    
-   输出是一个长度为 $M_l$ 的向量。
    

然后经过 softmax：

$$
b_{ij}^{(l)} = Softmax(\phi^{(l)}(v_i, v_j))
$$

这样得到的 $b_{ij}^{(l)}$ 就表示这条边对不同 anchor prompts 的选择权重。

最终：

$$
e_{ij}^{(l)} = \sum_{m=1}^{M_l} b_{ijm}^{(l)} p_m^{(l)}
$$

---

# 5\. EdgePrompt 和 EdgePrompt+ 的区别

| 方法 | 边 prompt 形式 | 表达能力 | 参数量 |
| --- | --- | --- | --- |
| EdgePrompt | 所有边共享一个 prompt | 较弱 | 小 |
| EdgePrompt+ | 每条边由多个 anchor prompts 加权组合 | 更强 | 适中 |

可以理解为：

-   **EdgePrompt**：每层只有一个全局边提示；
    
-   **EdgePrompt+**：每层有多个基础边提示，每条边根据节点关系动态组合。
    

论文实验也显示，EdgePrompt+ 通常优于 EdgePrompt。

# 6\. 下游任务训练方式

在下游任务中，预训练 GNN 是冻结的。

训练的参数主要包括：

1.  edge prompt 参数；
    
2.  score function 参数；
    
3.  下游分类器 $g$。
    

对于节点分类，给定 labeled node set $V_L$，优化目标是：

$$
\min \frac{1}{|V_L|} \sum_{v_i \in V_L} \ell_D(g(f(G')_i), y_i)
$$

其中：

-   $G'$：加入 edge prompts 后的 prompted graph；
    
-   $f$：冻结的预训练 GNN；
    
-   $g$：下游分类器；
    
-   $y_i$：节点标签；
    
-   $\ell_D$：分类损失，一般是交叉熵。
    

重点是：

> 预训练 GNN 本身不更新，只通过边 prompt 改变消息传递过程，从而适配下游任务。

---

# 7\. 用于节点分类

对于节点分类，流程如下：

```
输入：预训练 GNN f，图 G=(V,E)，少量标注节点 VL  
  
1\. 冻结预训练 GNN f  
2\. 在每条边上加入 edge prompt  
3\. 每层消息传递时，同时聚合邻居表示和边 prompt  
4\. 得到节点表示 h\_i  
5\. 用分类器 g 对节点 h\_i 分类  
6\. 只更新 edge prompts、score function 和分类器
```

与节点 prompt 相比，EdgePrompt+ 的优势是：

-   节点 prompt：一个节点给所有邻居传同一个 prompt；
    
-   边 prompt：同一个节点通过不同边给不同邻居传不同 prompt。
    

这可以缓解论文所说的 **uniform message passing on prompt vectors** 问题。

---

# 8\. 用于图分类

图分类任务中，输入是一组图：

$$
\{G_1, G_2, ..., G_K\}
$$

每张图有一个标签：

$$
\{y_1, y_2, ..., y_K\}
$$

EdgePrompt 的处理方式和节点分类类似，先在每张图的边上加入 edge prompts，然后用冻结的 GNN 得到节点表示。

接着用 READOUT 函数得到整图表示：

$$
h_G = READOUT(\{h_i | v_i \in V\})
$$

READOUT 可以是：

-   mean pooling；
    
-   sum pooling；
    
-   max pooling。
    

然后用分类器预测图标签：

$$
g(h_G)
$$

优化目标为：

$$
\min \frac{1}{K} \sum_{k=1}^{K} \ell_D(g(f(G_k')), y_k)
$$

所以 EdgePrompt 不仅适用于节点分类，也适用于图分类。论文强调它具有较好的 **downstream task universality**。

# 9\. 理论分析部分

论文主要给了两个理论分析。

## 9.1 节点分类理论：提高类别可分性

论文使用 CSBM，也就是 contextual stochastic block model，来分析节点分类。

简单来说，CSBM 假设：

-   图中有两个类别 $c_1, c_2$；
    
-   类别 $c_1$ 的节点特征服从：
    

$$
x_i \sim \mathcal{N}(\mu_1, I)
$$

-   类别 $c_2$ 的节点特征服从：
    

$$
x_i \sim \mathcal{N}(\mu_2, I)
$$

-   同类节点之间连边概率是 $p$；
    
-   异类节点之间连边概率是 $q$。
    

论文证明：存在一组 anchor prompts 和边权重，使得经过 GCN 聚合之后，两类节点中心之间的期望距离可以被放大。

也就是说，EdgePrompt+ 可以让两类节点表示更容易被线性分类器分开。

直观理解是：

> 边 prompt 可以调节消息传递过程，让同类信息更容易聚合，异类干扰更容易被削弱，因此提升节点分类性能。

---

## 9.2 图分类理论：具有通用图变换能力

论文还证明，对于任意一种图变换：

$$
G' = T(G)
$$

存在一组 EdgePrompt，使得预训练 GNN 在原图加 edge prompts 后得到的表示，可以等价于它在变换图 $G'$ 上得到的表示：

$$
f(X, A, \{p^{(1)}, ..., p^{(L)}\}) = f(X', A')
$$

这个结论想说明：

> EdgePrompt 具有较强的表达能力，可以模拟很多图 prompt transformation 的效果。

而 EdgePrompt+ 比 EdgePrompt 更细粒度，所以理论上表达能力更强。

---

# 10\. 和已有方法的区别

这篇论文最重要的区别是 prompt 插入位置不同。

| 方法 | Prompt 加在哪里 |
| --- | --- |
| GPPT | task embedding |
| GraphPrompt | readout |
| GraphPrompt+ | hidden representation |
| All-in-one | node feature |
| GPF / GPF-plus | node feature |
| MultiGPrompt | hidden representation |
| EdgePrompt / EdgePrompt+ | edge aggregation |

所以 EdgePrompt 的创新点不是重新设计预训练任务，而是：

> 在冻结预训练 GNN 的情况下，从边级消息传递角度设计 prompt。

这让它可以兼容多种预训练方式，例如：

-   GraphCL；
    
-   SimGRACE；
    
-   EP-GPPT；
    
-   EP-GraphPrompt。

# 11\. 方法整体流程总结

```
输入：  
\- 图 G=(V,E)  
\- 节点特征 X  
\- 已预训练 GNN f  
\- 下游少量 labeled data  
  
步骤：  
1\. 冻结预训练 GNN f  
2\. 对每一层 GNN，设置边 prompt  
   - EdgePrompt：每层一个全局 prompt  
   - EdgePrompt+：每层多个 anchor prompts  
3\. 对每条边，根据两端节点表示计算 prompt 权重  
4\. 用 anchor prompts 的加权和生成该边的 prompt  
5\. 在 GNN 消息传递时同时聚合：  
   - 邻居节点表示  
   - 边 prompt 向量  
6\. 得到节点表示或图表示  
7\. 用下游分类器完成节点分类或图分类  
8\. 训练时只更新 prompt 参数和分类器，不更新预训练 GNN
```

---

# 12\. 一句话总结

这篇论文的核心方法是：

> EdgePrompt 将 graph prompt tuning 从节点层面推进到边层面，在每条边的消息传递中加入可学习 prompt；EdgePrompt+ 进一步通过 anchor prompts 和注意力权重为不同边生成定制化 prompt，从而在冻结预训练 GNN 的前提下，更有效地适配节点分类和图分类任务。
