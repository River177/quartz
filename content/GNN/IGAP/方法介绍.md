这篇 **IGAP（Inductive Graph Alignment Prompt）** 的方法，核心可以先概括成一句话：

**它不是只像已有 graph prompt 那样把下游任务形式改写成预训练任务形式，而是进一步从“数据分布差异”入手，在谱空间里同时对齐图信号和图结构，再用任务提示把分类任务改写成对比/链接预测形式，从而让预训练 GNN 能从 transductive 推广到 semi-inductive 和 inductive 场景。**



这篇论文要解决的问题很明确。作者认为，现有 graph prompt 方法大多默认：

-   预训练图和微调图是“兼容”的
    
-   所以只要把下游任务重写成类似 pretext task 的形式就够了。
    
    
    

这在 **transductive** 场景还勉强成立，但在 **inductive** 场景里会出问题，因为微调图可能和预训练图差别很大，而且预训练数据本身往往不可访问。作者把这种差异称为 **data gap**，并进一步拆成两类：

1.  **graph signal gap**：节点特征分布变了
    
2.  **graph structure gap**：图拓扑/谱空间变了。
    
    
    

所以 IGAP 的方法不是单一 prompt，而是三类 prompt 一起工作：

-   **graph signal prompt $P_s$**：补偿图信号差异
    
-   **spectral alignment prompt $P_t$**：对齐谱空间
    
-   **label prompt $P_l$**：把下游分类任务改写成与预训练一致的对比形式。
    
    
    

---

## 1\. 先从谱理论解释“预训练到底学到了什么”

这是这篇论文最特别的地方。作者不是直接上 prompt 设计，而是先从 graph spectral theory 分析预训练本质。

他们先把主流 graph pre-training 统一成 **InfoNCE 式对比学习框架**：

$$
InfoNCE = -\sum_i \log \frac{\text{sim}(\sigma(f_\theta(G_i)),\sigma(f_\theta(G_i^+)))} {\sum \text{sim}(\sigma(f_\theta(G_i)),\sigma(f_\theta(G_i^{-/+})))}
$$

这里不同方法的差别，只体现在：

-   正样本怎么造
    
-   负样本怎么造
    
-   相似度怎么定义。
    
    
    

比如：

-   **subgraph contrastive learning**：同一节点中心的小扰动 ego-subgraph 是正样本，不同节点的 ego-subgraph 是负样本
    
-   **link prediction**：有边的节点对对应正样本，无边节点对对应负样本
    
-   **local-global contrastive learning**：局部子图和整图是正对，和打乱后的图是负对。
    
    
    

在此基础上，作者从谱域推导出一个关键结论：

**graph pre-training 更倾向于让图信号与低频谱成分对齐，而不是高频成分。**  
也就是论文里的 Theorem 1。



这一步非常重要，因为它给了 IGAP 一个设计原则：

> 既然预训练知识主要集中在低频谱空间，那么在 inductive fine-tuning 时，不需要硬对齐整个图，只要尽量把目标图的低频部分对齐到预训练图对应的低频空间，就能把预训练知识“接”过来。
> 
> 

---

## 2\. IGAP 的整体思路：先对齐数据，再对齐任务

基于上面的结论，IGAP 在微调阶段做三件事：

### 第一步：用 **graph signal prompt** 对齐节点信号分布

解决 graph signal gap。



### 第二步：用 **spectral alignment prompt** 对齐低频谱空间

解决 graph structure gap。



### 第三步：用 **label prompt** 把分类任务改写成对比形式

解决 pre-training objective 和 downstream objective 的 task-type gap。



也就是说，这篇方法不是只做“任务重写”，而是 **数据对齐 + 任务对齐** 一起做。



---

## 3\. Graph Signal Prompt：补偿节点特征分布差异

作者先处理第一类 gap：**graph signal gap**。

他们把微调图和预训练图之间的节点特征差异，看成一种“图信号扰动”，于是对每个节点信号 $x_i$ 做补偿：

$$
\tilde x_i = x_i + p_i
$$

其中 $p_i$ 是 prompt。



但如果每个节点都单独学一个 prompt，会有两个问题：

-   参数太多
    
-   few-shot 下容易过拟合。
    
    
    

所以作者没有给每个节点单独一个完整 prompt，而是定义一组共享的 **graph signal prompts**：

$$
P_s = [p_{s1},\dots,p_{sL}]
$$

然后每个节点的补偿由这组 basis prompts 的线性组合给出：

$$
\tilde x_i = x_i + \sum_j \alpha_i^j p_{sj}
$$

其中 $\alpha_i^j$ 是可学习系数。



这个设计很像字典表示：

-   $P_s$ 是少量共享的 prompt 基向量
    
-   每个节点只学“怎么混合这些基向量”
    

这样复杂度从原本的 $O(N\times F)$ 降到：

$$
O(N\times L + L\times F), \quad L\ll N
$$

既降低了参数规模，也降低了过拟合风险。



你可以把这部分理解成：

**先把微调图的节点信号“往预训练图熟悉的方向推一点”。**

---

## 4\. Spectral Alignment Prompt：对齐低频谱空间

这是 IGAP 的第二个、也是最核心的模块。

作者认为，graph structure gap 本质上就是：

**预训练图和微调图的谱空间不一致。**



预训练 GNN 学到的滤波器其实是在预训练图的谱基底上定义的。如果直接拿到新图上，这些滤波器可能就“不认路”了，因为基底变了。



### 4.1 为什么只对齐低频空间

根据前面的 Theorem 1，预训练知识主要集中在低频成分。  
所以作者不去强行对齐整个谱空间，而只对齐 **$K$ 个最小特征值对应的低频子空间**。



设：

-   预训练图的谱基底为 $U_{pt}$
    
-   微调图的谱基底为 $U_{ft}$
    

只取它们前 $K$ 个低频方向：

-   $U_{pt}^K$
    
-   $U_{ft}^K$。
    
    
    

但问题在于：**预训练图不可访问**，所以 $U_{pt}^K$ 也不可直接拿到。  
于是作者引入一个可学习的 **recessive transformation matrix prompt** $P_t$，让它隐式满足：

$$
U_{pt}^K = P_t U_{ft}^K
$$

也就是：用一个 learnable matrix prompt，把当前 fine-tuning graph 的低频基底映射到预训练图对应的低频空间。



### 4.2 对齐后的谱域卷积

在这个对齐空间里，微调图信号先经过 signal prompt 补偿得到 $\tilde X$，然后被投到对齐后的低频空间：

$$
\tilde Z = P_t U_{ft}^K g_\theta(\Lambda_{ft}) U_{ft}^{K\top} P_t^\top \tilde X
$$

这里 $g_\theta(\Lambda_{ft})$ 是预训练 GNN 在谱域中的滤波器。



这一步的意思是：

**虽然我们拿不到预训练图，但可以通过一个 learnable 的 $P_t$，让微调图的低频空间“长得像”预训练图的低频空间，于是预训练 GNN 学到的低频知识还能继续用。**

### 4.3 为什么不对齐全部谱成分

论文专门解释了这一点。  
如果把所有谱成分都对齐，会引入大量高频噪声；  
但如果对齐得太少，又会丢掉有用模式。  
所以要在“保留低频知识”和“避免高频噪声”之间折中，选一个 $K$。



所以 spectral alignment prompt 的本质是：

**不显式访问预训练图，只通过一个 learnable spectral prompt，把新图的低频空间拉到预训练知识可以发挥作用的位置。**



---

## 5\. Label Prompt：把分类任务改写成对比学习形式

处理完数据 gap 之后，作者再处理 **task-type gap**。

他们指出，节点分类和图分类的交叉熵损失，其实也可以改写成一种“与标签表示做相似度匹配”的形式。  
也就是说，如果把每个类别都看成一个 trainable label representation，那么分类其实就是：

**输入表示更接近正确 label prompt，远离其他 label prompts。**



于是他们为 $d$ 个类别引入 trainable label prompts：

$$
P_l = [p_1,\dots,p_d]
$$

然后把分类 loss 写成 InfoNCE 风格：

$$
InfoNCE = -\sum_i \log \frac{\text{sim}(p_i,\tilde z_i)} {\sum_j \text{sim}(p_j,\tilde z_i)}
$$

这里 $\tilde z_i$ 是前面经过信号对齐和谱空间对齐后的表示。



所以 IGAP 的第三个 prompt 不再是给输入图加东西，而是：

**给标签空间加可学习表示，让下游分类在形式上更接近预训练时的对比学习目标。**

这一点和很多 graph prompt 方法类似，但 IGAP 的不同在于：它前面已经先做了数据级对齐，所以这里的 label prompt 是建立在“信号和谱空间已经部分匹配”的基础上的。



---

## 6\. 最终优化目标

把三部分合起来，IGAP 的最终优化变量是：

-   graph signal prompts $P_s$
    
-   spectral alignment prompt $P_t$
    
-   label prompts $P_l$
    

优化目标写成：

$$
\arg\min_{(P_s,P_t,P_l)} -\sum_i \log \frac{\text{sim}(p_i,\tilde z_i)} {\sum_j \text{sim}(p_j,\tilde z_i)}
$$

并满足：

$$
\tilde Z = P_t U_{ft} g_\theta(\Lambda_{ft}) U_{ft}^\top P_t^\top \tilde X
$$

其中 $g_\theta$ 固定，也就是**预训练 GNN 是冻结的**，真正学的是这些 prompts。



所以整套方法不是 fine-tune encoder，而是：

-   先用 $P_s$ 调信号
    
-   再用 $P_t$ 调谱空间
    
-   最后用 $P_l$ 调任务形式。
    
    
    

---

## 7\. 这篇方法和以往 graph prompt 的本质区别

我觉得 IGAP 和此前方法最大的区别有两点。

### 第一，它关注的是 inductive data gap，而不只是 task gap

GPPT、GraphPrompt、All-in-One 这类方法，核心大多是：

-   把 node classification / graph classification 改写成 link prediction 或 graph-level matching
    
-   解决的是“任务形式不一致”的问题。
    
    
    

但 IGAP 认为在 inductive 场景下，**任务形式差异不是唯一问题，图本身的数据分布差异更严重**。  
所以它把 attention 转向：

-   graph signal gap
    
-   graph structure gap。
    
    
    

### 第二，它在谱空间做 prompt，而不是只在原始输入或标签空间做 prompt

IGAP 最核心的创新就是 spectral alignment prompt。  
也就是说，它不是只改输入特征，也不是只加 label token，而是显式从谱理论出发，在 **low-frequency spectral space** 做对齐。



所以这篇方法其实更像：

**transfer learning + spectral alignment + prompting** 的结合体。



---

## 8\. 一句话总结

**IGAP 先用谱理论分析 graph pre-training，指出预训练知识主要集中在低频成分；然后在 inductive fine-tuning 阶段，用 graph signal prompt 补偿节点信号差异，用 spectral alignment prompt 隐式对齐 fine-tuning 图与 pre-training 图的低频谱空间，再用 label prompt 把分类任务改写成对比形式，从而在不访问预训练图、且冻结预训练 GNN 的前提下，缩小 inductive 场景中的 data gap 和 task gap。**
