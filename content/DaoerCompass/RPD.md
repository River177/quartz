# **3. 页面 PRD（完整）**

## **3.1 Landing Page（/）——叙事型滚动官网**

### **3.1.1 页面目标**

用一页滚动的方式展示核心价值与效果演示，并提供两个主入口：

1. 选学校学院进入分类树
    
2. 先选专业看学校 Ranking（多榜单切换）
    

### **3.1.2 页面结构（ 8 个 Section）**

> 每个 Section：标题 + 一句解释 + 视觉展示（mock/动效）+ CTA（若适用）

**Section A：Hero 首屏**

- 标题：导向标：AI 导师信息收集与导航
    
- 副标题：公开主页结构化 + 研究方向分类树 + 多源比对深度搜索
    
- 两个 CTA：
    
    - CTA1「选择学校/学院进入」
        
    - CTA2「先选专业看学校 Ranking」
        
- 视觉：产品界面大图（分类树 + 导师卡片 + 报告卡片）
    

**Section B：痛点 → 解决**

- 左侧：传统方式（网页分散、信息不一致、难对比）
    
- 右侧：导向标（统一结构化、方向树、深度比对）
    
- 视觉：对比示意图
    

**Section C：功能展示 1——分类树导航（重点）**

- 展示点：
    
    - 整页分类树
        
    - hover 节点旁浮层导师列表
        
    - click 打开右侧导师列表面板
        
- 视觉：短动效/GIF/滚动触发动画
    

**Section D：功能展示 2——导师结构化详情**

- 展示信息块：基本信息/方向/论文/成果/教学/获奖/就业（有则展示）
    
- 展示“来源/更新时间”标识
    

**Section E：功能展示 3——深度搜索（外部检索+新爬取+多源比对）**

- 展示流程：点击深度了解 → 任务进度 → 多源报告卡片
    
- 显示“消耗积分”提示与“来源徽标/引用列表”
    

**Section F：Ranking（专业→学校，多榜单切换）**

- 专业选择器 + 榜单 Tabs（board）
    
- 学校排名列表（点击进入该校探索）
    
- 试点提示（当前开放 1–3 校）
    

**Section G：个人中心（收藏/画像/积分/邀请）**

- 收藏夹卡片：收藏导师、快速回访
    
- 画像卡片：偏好总结（可关闭/可清除）
    
- 邀请卡片：邀请奖励积分
    

**Section H：Footer**

- 数据来源声明、隐私/条款、联系方式、试点说明
    

### **3.1.3 Landing 的关键交互**

- CTA1：打开“学校/学院选择浮层”
    
    - 选择完成 → 跳 /explore?schoolId=&collegeId=
        
- CTA2：滚动到 Ranking 区块并聚焦专业选择（或打开浮层）
    
    - 选专业 → 默认榜单 board
        
    - 切换榜单 Tabs → 列表更新
        
    - 点击学校 → 如需学院则弹出学院选择 → 跳 /explore?...
        

### **3.1.4 状态与异常**

- 试点学校为空：显示“当前暂无开放学校”
    
- 榜单无数据：显示“该榜单暂未配置”
    
- 网络错误：在 section 内显示重试按钮，不影响整页浏览
    

### **3.1.5 埋点**

- landing_view_section（带 sectionId）
    
- landing_click_cta_school
    
- landing_click_cta_ranking
    
- landing_select_major
    
- landing_switch_board
    
- landing_click_school_from_ranking
    

## 3.2 分类树页面（/explore）——整页树 + Hover 浮层 + Click 侧栏

### **3.2.1 页面目标**

让用户通过三级方向树快速定位研究方向，并在 hover 与 click 两种粒度下浏览导师列表。

### **3.2.2 页面布局**

- 主体：**整页分类树**（居中/全宽）
    
- **右侧导师列表面板默认不显示**
    
- 顶部：面包屑（学校/学院） + 导师名搜索框（同全站） + 当前上下文提示（试点）
    

### **3.2.3 树的展示规则**

- 默认展开到二级（一级展开、二级展开、三级折叠）
    
- 节点展示内容：
    
    - 节点名
        
    - （可选）导师数量徽标 mentorCount
        
- 视觉层级：
    
    - 一级：大标题分组
        
    - 二级：可展开列表
        
    - 三级：叶子项/标签式
        

### **3.2.4 Hover 交互（节点旁浮层导师列表）**

**触发对象：二级节点、三级节点**

- Hover 后在节点旁出现 Popover：
    
    - 区块 1：节点介绍（intro + keywords）
        
    - 区块 2：导师列表预览（Top 5–8，按拼音）
        
- Popover 行为：
    
    - 鼠标从节点移到 Popover 时不消失（hover 可停留）
        
    - 200ms 防抖出现，150ms 防抖消失（避免抖动）
        
- Popover 内导师列表：
    
    - 显示姓名/职称（可选学院）
        
    - 点击导师 → 跳转导师详情 /mentor/:id?fromNodeId=...
        
    - “查看全部导师”按钮 → **等同于 click 节点，打开右侧面板**
        

### **3.2.5 Click 交互（右侧导师列表面板）**

- 点击二级或三级节点：
    
    - 右侧滑出 Drawer/Panel（占 30%~40% 宽）
        
    - Panel 顶部：节点名称、关闭按钮、（可选）导师数
        
    - 列表：分页（默认 20/页），按拼音 A→Z
        
    - 列表项点击：进入导师详情
        
- URL 同步：
    
    - 打开面板后：/explore?...&nodeId=xxx
        
    - 关闭面板：移除 nodeId（保持可回退）
        

### **3.2.6 空状态**

- Hover 浮层无导师：显示“该方向暂无导师（试点中）”
    
- Panel 无导师：显示空状态 + 推荐相邻节点（同层级）
    

### **3.2.7 埋点**

- explore_view
    
- explore_hover_node（nodeId、level）
    
- explore_open_preview_list（hover 展开成功）
    
- explore_click_node（nodeId）
    
- explore_open_panel / explore_close_panel
    
- explore_click_mentor_from_preview / explore_click_mentor_from_panel
    

## **3.3 导师详情页面（/mentor/:mentorId）**

### **3.3.1 页面目标**

展示导师结构化档案，支持收藏与深度搜索，并在左侧提供上下文导航（所属分类 + 同类导师）。

### **3.3.2 页面布局**

- 左侧栏：上下文导航
    
    - 区块 A：导师所属分类（可多项，点击返回 explore 并自动打开对应 panel）
        
    - 区块 B：同类导师（基于当前 导师的所有研究方向 ）
        
- 主内容区：导师结构化信息（分块折叠/锚点导航）
    
- 顶部右侧工具区：
    
    - 积分余额
        
    - 收藏按钮（切换态）
        
    - 深度了解按钮（消耗积分）
        

### **3.3.3 结构化信息块**

1. **基本信息**
    

- 姓名、职称、单位/学院/实验室
    
- 联系方式（邮箱/电话/地址，若公开）
    
- 教育经历（时间线）
    
- 个人照片
    
- 原始主页链接（必有）
    
- 数据更新时间 lastCrawledAt
    

2. **研究方向**
    

- taxonomy 归属标签（可点击）
    
- 自由文本方向（来自主页解析）
    
- 关键词（系统提取/人工补充）
    

3. **科研成果**
    

- 项目/基金（若有）
    
- 专利（若有）
    
- 代表性成果（若有）
    

4. **教学成果**
    

- 课程、教学项目、教学奖项（若有）
    

5. **获奖情况**
    

- 奖项列表（若有）
    

6. **论文列表**
    

- 标题、年份、venue、链接、来源（主页/外部源）
    
- 支持关键词筛选（可选）
    
- 支持按年份倒序（注意：导师列表排序仍是拼音；论文列表内部可按时间）
    

7. **就业**
    

- 学生去向/合作企业（若主页存在）
    

> 规则：某块无数据则默认折叠并提示“暂无公开信息”。

### **3.3.4 收藏**

- 未登录：点击收藏 → 弹登录引导
    
- 已登录：收藏/取消收藏即时生效
    
- 收藏后：在按钮旁显示“已收藏”并给“去收藏夹”快捷入口
    

### **3.3.5 深度 Agent 搜索（任务化，多源比对）**

- 点击“深度了解” → 确认弹窗：
    
    - 本次执行内容说明：外部检索 + 新爬取 + 多源比对
        
    - 消耗积分 N
        
    - “开始”按钮
        
- 任务状态展示：
    
    - 状态条：排队/执行中/生成报告/完成
        
    - 可关闭弹窗但页面保留任务卡片（顶部或成果区）
        
- 成功后展示“深度报告”模块（置顶或单独 Tab）
    
    - 报告结构建议：
        
        - 方向解读（通俗版）
            
        - 代表作与贡献总结
            
        - 近期动态/合作线索（如果外部源支持）
            
        - 风险提示（信息不一致处列出“冲突点”）
            
        - 来源列表（可展开）
            
- 失败处理：
    
    - 显示失败原因 + 重试按钮
        
    - 是否退分由后端决定，前端展示由返回字段控制（如 refunded=true）

# **4. Agent（全站悬浮入口）**

### **4.1 入口与形态**

- 右下角悬浮按钮（全站可见）
    
- 打开后为右侧抽屉式对话面板

    - 后台推导并形成记忆/画像
        
    - 用户可在设置中关闭与清除

# 5. 管理端（/admin/*）

### **5.1 试点配置（/admin/trials）**

- 选择开放学校/学院（开关）
    
- Landing 展示内容配置（试点提示、展示学校列表）
    

### **5.2 分类树维护（/admin/taxonomy）**

- 节点增删改（父子关系、层级）
    
- 节点 intro、keywords 编辑
    
- 同级排序
    
- 导入/导出 JSON（便于批量编辑）
    

### **5.3 导师管理（/admin/mentors）**

- 导师列表（按学校/学院筛选）
    
- 导师详情编辑（结构化字段修正）
    
- 重复导师合并（merge）
    
- 与 taxonomy 节点的映射关系编辑
    

### **5.4 数据更新工具（/admin/crawl）**

- 单导师更新：
    
    - 通过 mentorId 或主页 URL 触发更新
        
- 批量更新：
    
    - 按学校/学院批量触发
        
- 更新日志：
    
    - 成功/失败原因
        
    - 更新时间、耗时、外部 API 返回码
        

### **5.5 榜单配置（/admin/rankings）**

- 榜单 board 管理（名称、年份、来源说明）
    
- 专业 major 与 board 的排行数据上传/编辑
    

### **5.6 积分（/admin/points）**

- 配置深度搜索消耗 N、注册/邀请奖励
    
- 查看流水
    
- 手动给用户加/扣积分（用于试点运营）
